# 文言文实词抽题系统

本项目是一个基于 Python + Tkinter 的桌面端工具，用于从 Excel 表格中提取文言实词数据，并自动生成三种格式的学习资料：

- **Word 练习题**（每日默写卷）
- **PowerPoint 课堂展示题**
- **Word 知识手册**（实词义项汇总）

---

## 🚀 主要功能

### 1. 智能数据读取
- 支持导入自定义 Excel 表格（格式见下文）
- 自动统计实词总数、义项总数、例句总数
- 过滤空行与无效数据

### 2. 三种输出模式

| 模式 | 输出格式 | 用途 |
|------|----------|------|
| 输出 docx 题目 | `.docx` | 每日默写练习（题目 + 答案分页） |
| 输出 pptx 题目 | `.pptx` | 课堂投影练习（每页10题，答案标红） |
| 输出 docx 知识手册 | `.docx` | 实词义项复习手册（含拼音、例句、翻译） |

### 3. 灵活的配置选项
- **序号范围**：指定抽取的数据区间
- **生成篇数**：一次生成多份独立试卷
- **每篇题量**：控制每份试卷的题目数量
- **难度分配**：可选按难度比例（1~5级）分配例句，支持精确小数（总和=1）
- **顺序/乱序**：同一实词的例句是否集中放置

### 4. 完全 GUI 操作
- 启动后先选择 Excel 文件
- 所有参数通过窗口控件设置，无需命令行
- 最终弹出保存对话框选择输出路径

---

## 📂 输入文件格式

程序依赖一个标准格式的 Excel 文件（`.xlsx` / `.xls`），每行为一个义项记录，第一行为标题行。关键列说明：

| 列 | 内容 | 备注 |
|----|------|------|
| A | 总序号 | 唯一标识，用于范围选择 |
| B | 实词/词组 | 可重复（同一实词多个义项） |
| C | 义项 | |
| D | 难度（1~5） | 用于难度分配模式 |
| E | 读音 | 可选 |
| I~W | 例句1~5及其出处、翻译 | 每义项最多5个例句，允许空缺 |

> 详细列定义请参阅项目内附带的示例文件或开发文档。
