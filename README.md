# 文言文实词抽题系统

本项目是一个基于 Python + Tkinter 的桌面端工具，用于从 Excel 表格中提取文言实词数据，并自动生成四种格式的学习资料：

- **Word 练习题**（每日默写卷）
- **PowerPoint 课堂展示题**
- **Word 知识手册**（实词义项汇总）
- **能力测试卷**（全量例句乱序输出）

---

## 🚀 主要功能

### 1. 智能数据读取
- 支持导入自定义 Excel 表格（格式见下文）
- 自动统计实词总数、义项总数、例句总数
- 过滤空行与无效数据

### 2. 四种输出模式

| 模式 | 输出格式 | 用途 |
|------|----------|------|
| 输出 docx 题目 | `.docx` | 每日默写练习（题目 + 答案分页） |
| 输出 pptx 题目 | `.pptx` | 课堂投影练习（每页10题，答案标红） |
| 输出 docx 知识手册 | `.docx` | 实词义项复习手册（含拼音、例句、翻译） |
| 能力测试模式 | `.docx` | 指定范围内全部例句乱序输出，综合考察 |

### 3. 灵活的配置选项
- **序号范围**：指定抽取的数据区间
- **生成篇数**：一次生成多份独立试卷
- **每篇题量**：控制每份试卷的题目数量
- **难度分配**：可选按难度比例（1~5级）分配例句，支持精确小数（总和=1）
- **顺序/乱序**：同一实词的例句是否集中放置
- **能力测试**：无需配置题量和难度，直接将指定范围内所有例句打乱输出

### 4. 完全 GUI 操作
- 启动后先选择 Excel 文件
- 所有参数通过窗口控件设置，无需命令行
- 最终弹出保存对话框选择输出路径

---

## 📂 输入文件格式

程序依赖一个标准格式的 Excel 文件（`.xlsx` / `.xls`），每行为一个义项记录，第一行为标题行。关键列说明：

| 列 | 内容 | 备注 |
|----|------|------|
| A | 总序号 | 唯一标识，用于范围选择 |
| B | 实词/词组 | 可重复（同一实词多个义项） |
| C | 义项 | |
| D | 难度（1~5） | 用于难度分配模式 |
| E | 读音 | 可选 |
| I~W | 例句1~5及其出处、翻译 | 每义项最多5个例句，允许空缺 |

> 详细列定义请参阅项目内附带的示例文件或开发文档。

## 🆕 v1.1 更新内容

### 新增「能力测试模式」

- **功能定位**：将指定序号范围内的**全部例句**打乱顺序输出，用于综合性自我检测
- **子配置极简**：仅需填写序号范围（起止），无需设置题量、难度、顺序等参数
- **输出格式**：`[自动序号].[例句]（[A列总序数]）    [实词]:________________`
  - 括号内为 Excel 表格 A 列的原始总序号，方便回溯定位
  - 实词后跟 16 个字符长度的下划线供手写填写
- **文档格式**：无标题、宋体五号（10.5pt）、单倍行距、页边距统一 1.27cm
- **交互流程**：输出完成后弹出文件保存对话框，用户自选保存路径

### 使用场景

> 当学生已完成阶段性学习后，可通过能力测试模式一次性生成覆盖所有义项的综合测验卷，快速检验整体掌握情况。

## 🐛 v1.2 更新内容

### 修复：pptx 题目编号连续性

- **问题**：v1.0/v1.1 中，pptx 题目模式和答案模式的编号是**按页重置**的——每页幻灯片都从 1 开始编号，翻页后重新归零，导致多页文档中题目和答案的编号无法一一对应。
- **修复**：引入全局编号计数器 `global_idx`（题目）和 `global_ans_idx`（答案），在遍历 10 条/页的切片时持续递增，不再随页面重置。
- **效果**：
  - 题目从第 1 题连续编号至第 N 题，跨页不断号
  - 答案同样从 1 连续编号至 N，与题目**严格一一对应**
  - 例如：第 1 页题目为 1~10，第 2 页为 11~20……答案页完全同步

### 修改位置

仅涉及 `generate_pptx_questions()` 函数内部：

| 修改点 | 修改前 | 修改后 |
|--------|--------|--------|
| 题目编号 | `enumerate(chunk, 1)` → 每页从 1 开始 | 新增 `global_idx` 计数器，跨页持续 +1 |
| 答案编号 | `enumerate(chunk, 1)` → 每页从 1 开始 | 新增 `global_ans_idx` 计数器，跨页持续 +1 |
| 页面内首行判断 | 复用编号变量 `idx == 1` | 改用独立变量 `idx_in_page == 1`，避免与全局编号混淆 |

> 该修复不影响 docx 题目模式（原本就是全局连续编号）和能力测试模式。

## 🛠 环境依赖

- Python 3.8+
- `openpyxl` —— 读取 Excel
- `python-docx` —— 生成 Word 文档
- `python-pptx` —— 生成 PowerPoint 演示文稿
- `tkinter` —— GUI 界面（Python 标准库自带）

安装依赖：

```bash
pip install openpyxl python-docx python-pptx
```
